## 下载方式

### 直接下载

点击文件进入后，点击 **Raw** 按钮即可下载。

### 命令行下载

```bash
curl -LO https://github.com/Lukazan001/Firmware-transfer/raw/main/C3-方形/en/v1.10.0/xmini-c3-en_v1.10.0.bin
```
